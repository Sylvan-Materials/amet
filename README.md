# amet - ametathetos
Immune to transposition. graph algorithms for symmetry, permutations, and graph invariants.
Header only at c++23 standard and based on graph-v3.

#### Provide algorithms:
- Bliss/Nauty-Style Automorphism
- VF2++
- Suurballe
