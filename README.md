# amet - ametathetos
Immune to transposition. graph algorithms for symmetry, permutations, and graph invariants.
Header only at c++23 standard and based on graph-v3.

#### Provide algorithms:
- Component Connectivity
  - Biconnected components *implemented*
- Bliss/Nauty-Style Automorphism
- VF2++ *implemented*
- Suurballe *implemented*
- Edmonds' Blossom
- Gomory-Hu Tree
- Planarity Testing and Embedding
- Deterministic Global Minimum Cut  (Nagamochi-Ibaraki)
- Bipartite Graph Automorphism Partitioning
- Dulmage–Mendelsohn Decomposition
- Maximum Weight Bipartite Matching / Assignment Problem

While header only there are doctest's coming
